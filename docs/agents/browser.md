# Работа с дашбордами через браузер

- Один `snapshot` на страницу → `find`, чтобы найти нужный элемент → `click`
  по ref. `evaluate` используйте только для компактного чтения состояния
  (значения полей, статусы), а не для выгрузки `document.body.innerText`
  целиком: лишний текст съедает контекст.
- После любого действия, меняющего DOM (добавление/удаление строки),
  ref-ы устаревают — берите свежий `snapshot`.
- В таблице Environment Variables Render кнопка удаления — иконка без текста
  (`button-critical-ghost-background`) в строке нужной переменной; кликайте
  её, а не «Copy value».
- После «Save, rebuild, and deploy» проверьте статус на странице Deploys и
  эндпоинт `/health`, а не только наличие зелёной галочки в дашборде.

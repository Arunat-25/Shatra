# Глоссарий

Канонические термины проекта «Шатра». Глоссарий — только про смысл слов, не про реализацию.

| Термин | Значение |
|---|---|
| **Шатра** | Алтайская настольная игра, ради которой существует проект. |
| **Партия** | Одна полная игра — от начальной расстановки до финала. |
| **Онлайн-партия** | Партия двух игроков с разных устройств, состояние которой ведёт сервер. |
| **Хотсит** | Партия двух игроков на одном устройстве: после каждого хода устройство передаётся другому игроку. Сервер и интернет не нужны. Реализован как клиентский режим: правила считаются на устройстве, состояние ведёт локальная сессия. |
| **Партия с ботом** | Партия, в которой одной из сторон управляет бот. |
| **Бот** | Автоматический игрок, выбирающий ходы по правилам шатры. |
| **Комната** | Онлайн-партия в ожидании второго игрока или в процессе; к ней присоединяются по списку в лобби или по ссылке. |
| **Лобби** | Экран со списком открытых комнат; точка входа в онлайн-игру. |
| **Ресинк** | Восстановление у игрока актуального состояния партии после потери связи. |
| **Легальные ходы** | Ходы, разрешённые правилами шатры в текущей позиции. |
